# Новый печатный MERIT-билет

`utils/pdfGenerator.js` теперь рисует билет программно через PDFKit.
Старый PNG-шаблон больше не используется для печати.

## Дизайн

- тёмно-синяя брендированная панель слева;
- оригинальный `assets/school-logo.png` вставляется один раз без наложения;
- кремовая основная часть;
- отрывной корешок справа;
- золотые линии и акценты;
- нет фразы `БИЛЕТ НА ПОКУПКУ`;
- нет фразы о том, что билет действует только в указанную дату;
- остаётся предупреждение о запрете передачи билета другому лицу;
- код печатается и в основной части, и на корешке.

## Шрифты

Все текстовые элементы билета используют:

`utils/fonts/CormorantGaramond-SemiBold.ttf`

Исключение - код билета. Для него используется более компактный:

`utils/fonts/GolosText-Medium.ttf`

Размер кода автоматически уменьшается под его реальную длину, поэтому
формат `MR-0123456789ABCDEF` помещается целиком и не переносится.

Если локальные TTF отсутствуют, генератор имеет системный fallback, но для
утверждённого вида нужно сохранить существующие Cormorant/Golos в `utils/fonts/`.

## Печать

Чтобы сохранить широкие пропорции утверждённого билета и читаемый текст,
генератор размещает по **2 билета на одном листе A4 portrait**.
