# Logo print fix

Исправлено два источника искажения школьного логотипа:

1. В `utils/assets/merit-ticket.png` четыре сгенерированных логотипа
   заменены на точный `assets/school-logo.png`.
2. `utils/pdfGenerator.js` больше не растягивает 4:3 шаблон до A4
   независимо по ширине и высоте. Используется единый масштаб с
   центрированием, поэтому круглый логотип остаётся круглым и текст
   внутри него не деформируется.

Для применения достаточно заменить эти два файла:
- `utils/assets/merit-ticket.png`
- `utils/pdfGenerator.js`
